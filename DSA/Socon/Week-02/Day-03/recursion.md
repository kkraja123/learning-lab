# Recursion

- It is a technique where a function solves a problem calling itself or smaller version of the problem unltil a base condition itself

## Components

1. Base Condition
2. Recursive case


Each frame inside stack remembering every such as:

1. parameter value
2. local variable
3. where the funtion used to continue after the recursion call

## Types

1. Direct Recursion
2. Indirect Recursion => a -> b -> a
3. Tail Recusrion => when the recursive call is the last statement
4. Head Recursion => when the recursive part is not the last statement
