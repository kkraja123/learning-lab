# Algorithm:

- An algorithm is a finite sequence of well-defined steps that transforms an input into the desired output.

Problem
      ↓
Think
      ↓
Algorithm
      ↓
Code
      ↓
Program

## Algorithm flow:

Input
   ↓
Process
   ↓
Output

This Pattern Appears Everywhere

Once you recognize it, you'll start seeing it in many problems.

## Maximum
- Maintain the largest value so far.
## Minimum
- Maintain the smallest value so far.
## Running Sum
- Maintain the total so far.
## Maximum Profit
- Maintain the best profit so far.
## Longest Substring
- Maintain the longest length so far.
## Dynamic Programming
- Maintain the best answer for each subproblem.

This single idea shows up in hundreds of interview questions.
