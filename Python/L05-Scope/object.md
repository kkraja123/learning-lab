Lesson 5.5 Summary

Today you learned:

✅ Everything in Python is an object.

✅ Variables (names) do not contain objects; they refer to objects.

✅ Functions are objects.

✅ Multiple names can refer to the same object.

✅ Deleting a name does not necessarily delete the object.

✅ Classes are objects.

✅ type() returns the object representing the type of its argument.
