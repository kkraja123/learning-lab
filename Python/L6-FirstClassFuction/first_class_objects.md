# First-Class Objects

- Functions are first-class objects because they can be treated like any other object.

A function object can be assigned to a variable.
A function can be passed as an argument to another function.
A function object can be returned from another function.

🎉 Lesson 6 Milestone

Without writing a single advanced program, you've established the mental model behind first-class functions:

✅ Functions are objects.
✅ Names are bound to function objects.
✅ Functions can be assigned to variables.
✅ Functions can be be passed as arguments.
✅ Functions can be be returned from functions.
✅ Multiple names can refer to the same function object.

That's the foundation.
